## Responsabilidade dos principais arquivos

| Caminho | Responsabilidade |
|---|---|
| `index.html` | Página principal e metadados. |
| `privacidade.html` | Política de privacidade. |
| `assets/css/style.css` | Estilos compartilhados do site. |
| `assets/css/privacy.css` | Estilos específicos da página de privacidade. |
| `assets/js/script.js` | Interações e conteúdo dinâmico. |
| `assets/js/contact-form.js` | Comportamento do formulário. |
| `robots.txt` | Orientação de rastreamento para robôs. |
| `sitemap.xml` | URLs públicas incluídas no sitemap. |
| `README.md` | Apresentação do repositório e instruções iniciais. |
| `CHANGELOG.md` | Registro resumido de mudanças relevantes. |
| `docs/` | Documentação técnica, operacional e histórica. |

Esta árvore reflete os diretórios e arquivos documentais principais verificados na branch `master`; não é um inventário individual de cada arquivo de mídia. Atualize-a quando diretórios ou responsabilidades forem alterados.
