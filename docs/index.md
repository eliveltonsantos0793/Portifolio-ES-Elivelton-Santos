# Documentação do Portfólio ES

Este diretório reúne a documentação técnica, operacional e histórica do Portfólio Elivelton Santos.

A documentação descreve a implementação conhecida do projeto e registra separadamente decisões, validações concluídas e atividades ainda pendentes. Ela não substitui o código-fonte nem deve ser interpretada como garantia de que serviços externos ou recursos em desenvolvimento estejam disponíveis.

## Escopo e atualização

- A implementação atual do portfólio utiliza HTML5, CSS3 e JavaScript puro.
- Não há migração para frameworks prevista nesta documentação.
- Recursos externos, como FormSubmit e WhatsApp, possuem dependências próprias e devem ser testados separadamente.
- Status de implementação, testes e pendências devem ser atualizados somente após verificação.
- Datas e registros históricos devem permanecer explícitos para evitar confundir o estado anterior com o estado atual do projeto.
